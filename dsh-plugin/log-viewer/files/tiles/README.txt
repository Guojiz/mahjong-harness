牌面素材来源

本目录使用 SakaiTaka23/riichi-mahjong-tiles 的 Regular/regular-merged SVG。
仓库 README 明确声明：All assets are in the public domain，并链接 CC0 1.0 公共领域声明。
原始作者：FluffyStuff/riichi-mahjong-tiles。

用途

- Regular-*.svg：正面、牌背、空白牌及赤五牌面。
- UI 使用 CSS 固定 30x40px 牌面槽；横牌只在 42px 固定槽内旋转 90deg。
- 牌面文件为 SVG，保持 300x400 原生宽高比，不因发牌数量或视口缩放。
